### Key System Pillars
- **Authoring:** Markdown-first collaborative editor (GFM), live preview/split view, syntax-highlighted code, tables, and internal link auto-complete.
- **Collaboration:** Real-time concurrent editing, live cursor awareness, contextual inline comments, user mentions (`@user`).
- **Topology & Discovery:** Bi-directional backlinks, interactive visual Knowledge Graph, permission-aware unified search.
- **Governance & Traceability:** 4-tier Dynamic Access Control with explicit user overrides, multi-author version snapshots, and immutable audit logging.
